# Pavithra's Journey — Interactive Figma Canvas Engineering Portfolio

An interactive, hyper-modern portfolio engineered as a **unified Figma design workspace** for **Pavithra Meddaduwage** — Database Programmer & Full Stack Software Engineer.

---

## 🎨 Unified Figma Workspace Features

### 1. 🖥️ Authentic Figma Infinite Dot-Grid Canvas
- **Clean, Logical Flow**: A structured, unified workspace without scattered or mismatched elements:
  1. `# Frame 00`: Hero & Systems Core Identity
  2. `# Frame Systematics`: Architecture Data Flow & Marching Wires
  3. `# Chapter 05`: Horizon Group USA — Data Ingestion & Storage Architecture
  4. `# Chapter 04`: Digisa — Commercial ERP Platforms & Inventory Systems
  5. `# Chapter 03`: XESS Global — Responsive Design Studio & Commercial Web
  6. `# Chapter 02`: CreativeHub — Headless CMS & GraphQL API Engineering
  7. `# Chapter 01`: SLIIT — Higher Education & Theoretical Foundations (BSc Hons & MSc)
  8. `# Frame SQL Terminal`: Live Interactive psql Console
  9. `# Frame Skills`: Component Library & Architecture Matrix
  10. `# Frame Contact`: Epilogue & Global Engineering Contact

### 2. 🌓 Complete Dark & Light Mode Support
- Seamless one-click toggle in the top toolbar:
  - **Light Mode**: Crisp `#f4f4f5` canvas with dark dot grid, clean white cards, `#e2e8f0` borders, and high-contrast dark typography.
  - **Dark Mode**: Sleek `#18181b` canvas with white dot grid, `#202023` panels, `#141417` cards, and glowing accents.

### 3. 🖱️ Authentic Figma Canvas Interactions
- **Interactive Frame Selection**: Selecting any frame displays Figma’s signature `#0d99ff` blue outline, 8 resize handles, `# Frame: Name` label, and red dimension lines (`32px`).
- **Draggable & Droppable Components**: Drag technology badges (`PostgreSQL`, `NestJS`, `Angular`, `Redis`, `Docker`) from the left asset tray onto the canvas with live particle feedback.
- **Keyboard Shortcuts**: Navigate smoothly between frames with `[↑]` / `[↓]` (or `[K]` / `[J]`).
- **Presentation Mode**: Press `[F]` or click `▶ Present` to hide sidebars for client presentations.
